BCHW → B×(CHW) Flatten Explorer

AI Accelerator Design · Assignment 3 · IIT Tirupati. Flatten and reconstruct a tensor with explicit index arithmetic, no reshape.

The mapping

flatten:     j = c·(H·W) + h·W + w
reconstruct: c = ⌊j / (H·W)⌋   r = j mod (H·W);   h = ⌊r / W⌋;   w = r mod W
