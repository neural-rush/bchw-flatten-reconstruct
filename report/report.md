## 1. Algorithms

Row-major mapping, with W varying fastest. CHW = C*H*W.

**Flatten**

    for b in 0..B-1:
      for c in 0..C-1:
        for h in 0..H-1:
          for w in 0..W-1:
            j = c*H*W + h*W + w
            out[b][j] = I[b][c][h][w]

**Reconstruct**

    for b in 0..B-1:
      for j in 0..CHW-1:
        c = j // (H*W)
        r = j %  (H*W)
        h = r // W
        w = r %  W
        out[b][c][h][w] = flat[b][j]

## 2. Manual indexing example

B=1, C=2, H=2, W=3, so CHW = 12 and H*W = 6.

| Element | Calculation | Flat index |
|---|---|---|
| I[0,0,0,0] | 0*6 + 0*3 + 0 | 0 |
| I[0,0,0,2] | 0*6 + 0*3 + 2 | 2 |
| I[0,0,1,0] | 0*6 + 1*3 + 0 | 3 |
| I[0,1,0,0] | 1*6 + 0*3 + 0 | 6 |
| I[0,1,1,2] | 1*6 + 1*3 + 2 | 11 |

Reverse check for j = 11: c = 11//6 = 1, r = 11%6 = 5, h = 5//3 = 1, w = 5%3 = 2.

## 4. Discussion

- Emax = MAE = 0 for every configuration, from C = 1 to C = 500.
- The mapping is a bijection between (c, h, w) and j in [0, CHW), and values are
  only copied, never computed on, so no rounding can occur.
- Cost is linear in the number of elements, B*C*H*W; the largest case (C = 500)
  took about one second in pure Python.
- Results matched an independent reshape-based reference, used for verification only.
- This layout is what a systolic array receives when feature maps are streamed
  as a linear buffer: channel-major, then row, then column.
